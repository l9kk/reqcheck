Как работает

Reader Segmenter Linter Auditor CrossChecker EdgeCaser WholeDoc Critic Clarifier Reconciler Отчёт
роль модели код Вход PDF, DOCX, MD, TXT. Отчёт MD, PDF, JSON, HTML. Номер строки к каждой цитате ставит код.

Пример из отчёта

39«На карту приходится максимум один такой push за календарный месяц»
40«следующее достижение вызывает push независимо от истории предыдущей настройки»
D-01критично Строки 39 и 40 противоречат друг другу.
Q-01бизнесу Отправляется ли второй push в том же календарном месяце? Три варианта с тестом, рекомендован (б).

Зачем

Ручная проверка этого ТЗ по нормам ревью: 0.3-2.3 ч и больше. Агент: один прогон.

Дефект требований, найденный только на тестах, в 21-78 раз дороже (NASA, 2004).

Ограничения

  • Список дефектов составили мы сами, независимой разметки нет.
  • Строгую проверку делал отдельный агент, не человек.
  • Время живых ревьюеров не засекали: ценность оценена по нормам.

Запуск

pip install -r requirements.txt
python -m reqcheck <ТЗ> -o out/report.md
Повтор на выданном ТЗ без ключа,
из кэша: команда в RESULTS.md
